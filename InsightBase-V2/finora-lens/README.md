# InsightBase V2 development

The authoritative agent handoff is [docs/README.md](../docs/README.md). Read the workspace and [V2 AGENTS.md](../AGENTS.md) before changes.

Source is `dist/`; final Windows files are generated by `package_three_files.py` in the sibling `InsightBase-Windows/` directory. It bundles exactly HTML, CSS and JS. The user supplies `dataa.xlsx` separately.

Every structural change must update the affected Markdown documentation in the same task. Follow [development instructions](../docs/DEVELOPMENT.md), [financial definitions](../docs/CALCULATIONS.md) and [data schema](../docs/DATA_CONTRACT.md). V1 was deleted with user authorization on 2026-10-09; V2 is the only maintained version.

From InsightBase-V2:

```sh
python3 finora-lens/package_three_files.py
node --test finora-lens/tests/engine.test.cjs
python3 finora-lens/preview_demo.py
```

See the development document for Windows startup, loopback preview, verification and known limitations. Legacy builders/migration helpers are not the active delivery workflow.

The presentation editor and native editable PowerPoint export are documented in [PPTX_EXPORT.md](../docs/PPTX_EXPORT.md). PptxGenJS 4.0.1 is vendored offline. Run engine and presentation tests together. Current presentation-phase changes must not be uploaded to GitHub until user instruction.

PDF indir is also available beside PowerPoint indir; it produces fixed 16:9 visual pages using offline jsPDF 3.0.3. The Windows application still has exactly three files.
