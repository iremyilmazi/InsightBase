# Sunum sürümü

[Sektor-Hikayesi.insightbase.json](Sektor-Hikayesi.insightbase.json), kullanıcı tarafından yayımlanması istenen güncel üç sayfalık sunumdur.

Güncel InsightBase uygulamasında **Sunum oluştur → Sürüm aç → dosyayı seç → Bu sürümü aç** yolunu kullanın. GitHub dosyasının Raw içeriğini UTF-8 olarak `.insightbase.json` uzantısıyla kaydedebilirsiniz. Dosyanın sonuna `.txt` eklenmemeli.

Grafikler o bilgisayardaki `dataa.xlsx` üzerinden yeniden hesaplanır. Tarih aralıkları, grafik ayarları ve metinler kaydedilir. Başlık ve yorumlar otomatik yazılmaz; Excel değiştiğinde ayrıca gözden geçirilmelidir. Kümülatif P&L grafiği ocak 2025–ağustos 2026 aralığındadır.

Bu sürüm şema 2 kullanır ve güncel uygulamayı gerektirir. Gerçek Excel, grafik gözlem serileri, PDF ve PowerPoint bu klasöre dahil edilmez. Bu dosyanın yayımlanması kullanıcının açık talebidir; diğer yerel sunumlar için izin oluşturmaz.
