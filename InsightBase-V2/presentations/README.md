# Sunum sürümü

[Sektor-Hikayesi.insightbase.json](Sektor-Hikayesi.insightbase.json), kullanıcı tarafından yayımlanması istenen güncel üç sayfalık v13 sunumudur.

Güncel InsightBase uygulamasında **Sunum oluştur → Sürüm aç → dosyayı seç → Bu sürümü aç** yolunu kullanın. GitHub dosyasının Raw içeriğini UTF-8 olarak `.insightbase.json` uzantısıyla kaydedebilirsiniz. Dosyanın sonuna `.txt` eklenmemeli.

Grafikler o bilgisayardaki `dataa.xlsx` üzerinden yeniden hesaplanır. Tarih aralıkları, grafik ayarları ve metinler kaydedilir. Başlık ve yorumlar otomatik yazılmaz; Excel değiştiğinde ayrıca gözden geçirilmelidir. Kümülatif P&L grafiği ocak 2025–ağustos 2026 aralığındadır.

Bu sürüm şema 3 kullanır ve güncel uygulamayı gerektirir. Gerçek Excel, grafik gözlem serileri, PDF ve PowerPoint bu klasöre dahil edilmez. Bu dosyanın yayımlanması kullanıcının açık talebidir; diğer yerel sunumlar için izin oluşturmaz.

22 Ekim 2026 güncellemesi: P&L tablosu aylık kaynaktan dönemsel YoY gösterir; üst grafik kümülatiftir. Mevduat payı açıklaması grafikteki büyüme ayrışmasına bağlanmıştır.
